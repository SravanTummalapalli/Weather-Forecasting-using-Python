# Weather Forecasting using Python 🌦️📊

This project demonstrates weather forecasting using Python, involving data cleaning, feature engineering, visualization, and machine learning-based prediction of weather parameters such as temperature, humidity, and wind speed.

## 📌 Project Overview

The goal of this project is to predict weather conditions based on historical weather data using regression models. It includes:

- Preprocessing real-world weather data
- Exploratory Data Analysis (EDA)
- Training predictive models
- Visualizing results

## 🛠️ Tools and Libraries Used

- `pandas` – Data manipulation
- `numpy` – Numerical operations
- `matplotlib` & `seaborn` – Visualization
- `sklearn` – Machine learning (linear regression, decision tree, etc.)
- `datetime` – Handling time-based features

## 🧾 Features and Functionality

### ✅ Data Preprocessing
- Handles missing values and inconsistent formats.
- Converts and standardizes datetime formats.
- Encodes categorical features.

### ✅ Exploratory Data Analysis (EDA)
- Line plots of weather metrics over time.
- Correlation matrix heatmaps.
- Seasonal and daily pattern trends.

### ✅ Weather Forecasting Models
- Linear Regression
- Decision Tree Regressor
- Random Forest (if implemented)
- Model evaluation using RMSE, MAE, and R² Score.

### ✅ Visualization
- Actual vs Predicted plots
- Feature importance
- Trends over time
